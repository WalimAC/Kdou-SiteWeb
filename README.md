## À propos du projet

Ce projet SAE 1.04 consistait à travailler sur la base de données commerciale fictive de l’entreprise **KDou** et à présenter les résultats via un site web.  
Le travail a été réalisé dans le cadre de la première année de BUT Informatique – Web S1.04 – Novembre 2025.

⛔️ | **Limitations du projet :**
- L’entreprise et les données sont fictives, donc le site n’est pas relié à une base réelle.  
- Les indicateurs et analyses sont uniquement à des fins pédagogiques.  
- Le site est un projet statique avec HTML/CSS/JS, sans backend réel.

### Missions réalisées
1. Analyse de la structure de la base de données (tables, relations, contraintes)  
2. Création de requêtes SQL sur Access pour extraction de données  
3. Analyse d’indicateurs et présentation des résultats  
4. Création d’un site web pour présenter le bilan des trois missions  
5. Rédaction d’un rapport web détaillant les travaux

[Voir un aperçu du site](https://kdou.free.nf)

---

### Structure du site

- **Home Page** — Introduction et contexte du projet  
- **Mission 1** — Analyse de la base de données  
- **Mission 2** — Requêtes SQL et extraction  
- **Mission 3** — Analyse des indicateurs  
- **Bilan** — Résumé des trois missions pour l’entreprise  
- **Rapport Web** — Détails méthodologiques et conclusions  

💡 | *Le site peut être amélioré avec des animations, un backend pour les données réelles, ou un CMS.*
